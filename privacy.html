Privacy

The short version: your sales file never leaves your computer, and the tool keeps nothing once the tab is closed.

Your files

  • The tool reads your file inside the browser tab. It is not uploaded to us or to anyone else.
  • The calculation runs in your browser, using a database engine that is downloaded as part of the page.
  • Exports (Excel, CSV, PNG and the HTML report) are created in your browser and saved by your browser.

What is stored, and where

  • By default, nothing. The data lives in the tab’s memory and is gone when you close or reload the tab, or choose Clear data.
  • If you tick Remember this setup in this browser, your column choices, attribute order and options are saved in your browser’s local storage. Filter selections are not saved, because they are values from your data. Unticking the box deletes what was saved.
  • The tool does not use IndexedDB, browser caches, a private file system or a service worker.
  • The site sets no cookies and has no accounts.

What we can see

  • The site has no analytics or tracking scripts and loads nothing from third parties.
  • The company hosting the site can see ordinary web server logs, such as the pages requested and IP addresses. It cannot see your files.

Checking this yourself

Open your browser’s developer tools, go to the network panel, and load a file. No request carries your data. The pages also carry a content security policy that only allows connections to this site, so the browser itself blocks anything else. The source code is published so anyone can confirm what the page does, and its automated test checks that nothing is stored or sent.

If this changes

Planned paid features such as saved workspaces across devices would store your setup on a server. This page will be updated before any such feature is released, and uploading data will never be required to use the free tool.
