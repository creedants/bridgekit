- One page is one `page_views` path per day and referrer. `/guide.html` and `/guide` both store `/guide`. The same collapse applies to `/method`, `/privacy`, `/price-volume-mix-analysis`, and `/grouping-level`. `/` and `/app/` stay as they are. A path that is not one of those pages is not counted.
- A referrer is stored as the host only, in lower case, with no port, user info, or path. The same site, an invalid host, a host that is not a real host name, and a host longer than 200 characters are stored as a direct visit. A host longer than 200 characters is not cut to 200 characters.
- A new foreign host is stored only while that page and day have fewer than 32 foreign hosts. A host row that already exists for that page and day is kept, so a page can hold more than 32. Further new hosts increment the referrer `other`. The check and the insert are one statement, after the response. Overlapping writes do not admit a new host past 32.
- `/pay/` is still served by the asset layer and is still not counted.
- The notes in `scripts/perf/worker.mjs` say `/guide.html` and `/method.html` answer 200 and are stored as `/guide` and `/method`. The page-count check reads those rows. `perf/worker-baseline.json` is still the earlier capture.
