- The row named with a text cell is the file's spreadsheet row. A line break inside a quoted cell no longer moves it, a blank record counts as a row, and a file with a space before an opening quote, CRLF line endings or a UTF-16 byte-order mark names the same row as an Excel workbook with those cells. Sales must be a column of numbers, and "NET_SALES" holds text, such as "n/a" in row 4.
- The sentence names no row when the source record count does not match the loaded table. For CSV, it also names no row when the located field does not hold the quoted text. It then reads Sales must be a column of numbers, and "NET_SALES" holds text, such as "n/a".
- A file whose measure column has no text cell reads nothing to find a row, so a clean numeric file loads and profiles without the extra pass over the file.
