- A CSV whose first 64 KB read as UTF-8 but whose later bytes are not UTF-8 now shows the existing file-encoding sentence instead of a raw database message, whatever wording the database uses. The decision reads the file's own bytes in bounded slices after a failed load, so no full buffer or decoded string of the file is built and a successful load does no extra pass. A file that ran out of memory keeps the too-big sentence, any other file error keeps its own message, and a check that cannot read the file keeps the database's error rather than the read failure.
