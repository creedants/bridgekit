- The period list is ordered once, by the query that reads it. The trend steps that order with no second sort. A period column counts as numbers only when every value is a plain digit string of at most 15 digits, so its values cast to finite numbers. Labels with unequal numbers order by value. Labels with equal numbers, such as `1`, `1.0` and `01`, remain separate periods and order by their original text. Every other period column keeps the previous text order.
