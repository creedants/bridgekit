- A text period column whose values all match one format lists and steps oldest first by the date each label names. The formats are `YYYY-Qn`, `YYYY Qn`, `Qn YYYY`, `Qn-YYYY`, `Mon YYYY`, `Month YYYY`, `YYYY-MM`, `FYnn` and `FYYYYY`, and quarter letters, month names and fiscal-year letters are read in either case. Labels that name the same period, such as `Q1 2025` and `q1 2025`, stay separate values and order by their original string after the date. A column that mixes two formats, such as `2025-Q1` with `2025 Q2` or `Jan 2025` with `January 2025`, or that holds a value matching none, keeps the previous text order, so `Actual` still comes before `Budget` and `Q1 2025` before `Q4 2024`. The order applies before the 200-period window, so a long column still keeps the latest 200 periods. Numeric period columns are unchanged.
