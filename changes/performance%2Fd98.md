- A text period column whose values all match one format lists and steps oldest first by the date each label names: `YYYY-Qn`, `YYYY Qn`, `Qn YYYY`, `Qn-YYYY`, `Mon YYYY` or `Month YYYY` in English in either case and either length, `YYYY-MM`, and `FYnn` or `FYYYYY` with a two-digit year read as 20nn. Labels that name the same period, such as `Q1 2025` and `q1 2025`, stay separate values and order by their original string after the date. A column that mixes two formats, or holds a value that matches none, keeps the previous text order (`Actual` before `Budget`, `Q1 2025` before `Q4 2024`). The order is applied before the 200-period window, so a long column still keeps the latest 200 periods. Numeric period columns are unchanged.
