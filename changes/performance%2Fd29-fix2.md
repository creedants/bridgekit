- Enforcement of the workspace and invitation limits moves out of triggers that undid a write after it happened. server/worker.ts now refuses, before Better Auth runs, a create by an account that already owns 3 workspaces and an invitation (new or re-sent) for a workspace with no seat, answering 403 with the same two sentences the plugin would; server/auth.ts keeps the same two checks in the plugin's own before-hooks for callers that reach it directly. `migrations/0004_workspace_limits.sql` now holds only `CREATE VIEW workspace_seats` and a `BEFORE INSERT` trigger and a `BEFORE UPDATE` trigger on `invitation`, each refusing only a write that leaves a live pending invitation the workspace has no seat for, that `RAISE(ABORT)` with the seat sentence when the workspace has no seat. The triggers read only capacity, the member rows and the subscription seats behind workspace_seats, and change and delete nothing elsewhere, and applying the migration changes no row, so it is safe to apply while an older Worker is serving: a write the trigger refuses fails and sends no email. When two invitations for the last seat arrive at once, the database refuses the losing insert and the Worker answers it with the same sentence, because `onAPIError.throw` lets the database error reach the Worker, which answers it with the same sentence; without the switch the refused write answers an empty 500 with no row and no email. The invitation email callback keeps only a check that its row still exists before sending. The two refusal sentences are "You can own up to 3 workspaces, so delete one before creating another." and "This workspace has no free seat, so cancel a pending invitation or add seats." Known limits, out of scope and not fixed here: two workspace creations by one account at the same moment may both succeed past the limit of 3; ownership gained by accepting an owner invitation or by a role change is not counted against the limit; an invitation accepted at the same moment as a new invitation is sent may leave the workspace one over its seats.
