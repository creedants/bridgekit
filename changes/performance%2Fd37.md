- The setup area now names the reason Calculate bridge stays off for a file the tool cannot bridge, instead of only the general line "Choose periods, units, sales and at least one attribute." A new pure function in `src/app/fileProblems.ts` picks the sentence, and `src/app/App.tsx` shows it in place of that line, or beside it for the period-column note. A file that loads and bridges, including the sample data, shows nothing new.
- The new sentences: "This file has no data rows, so there is nothing to bridge.", "The period column "<name>" has only one value, and a bridge compares two periods.", "Sales must be a column of numbers, and "<name>" holds text.", "Sales and Units must be columns of numbers, and this file has none.", and "The period column "<name>" holds more than 100 values, and a period column should hold a few period labels such as years or months."
- "Suggest attributes" now asks "Replace the attributes you chose with the suggested ones?" before it replaces a list the user already chose. The question and its Replace and Keep mine buttons sit in the panel's own style. An empty list is still filled without asking, a suggestion that equals the list changes nothing, declining changes nothing, and focus returns to the button after either answer.
