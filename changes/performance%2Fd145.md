A real sales export was read wrongly in four ways. A European money column of `1.979.849,56` stayed text, so Sales could not be chosen. `NaN` and the infinities filled the bridge. Slash dates with a time failed with the database's own error, and text dates stayed text. A file whose rows mixed `;` and `,` loaded with the wrong delimiter. A file that already worked loads with the same numbers.

- `src/app/numbers.ts` reads a value as a number only when it is finite, so `NaN`, `Infinity` and `-Infinity` stay text and the file problems message names the value and its row. The conversion gate counts a value under either money convention, so a column of many dot groups and a decimal comma reaches the decimal-comma decision. A column that proves two money styles carries the first value of the losing style and its row, when the file proves one, and the Data check sentence quotes both. `mixedSeparatorSentence` refuses a file whose rows do not all use one separator, decided from the first 64 KB.
- `src/app/db.ts` reads a CSV typed first and retries once when the database reports a conversion error, keeping every date, timestamp and time column as text so the reader can decide from every value. `convertDateColumns` reads slash dates and English month-name dates, with or without a time of day, becomes TIMESTAMP when any value carries a time and DATE otherwise, and leaves a column text when it proves both slash orders or mixes shapes. The order comes from the values that break the tie, then from the browser's language. The existing slash-date pass takes the same order. Non-finite cells return to the file's own text. `load()` refuses a mixed-separator CSV before it is staged, so the loaded data is left alone.
- `src/app/sheet.ts` returns the name of the worksheet it loaded and how many later sheets hold a header and a data row.
- `src/app/db.ts` writes that name on a staged workbook, and `src/app/numbers.ts` renders it in the Data check sentence: `The workbook's first sheet, "Sales", was loaded; the other sheet was not.`
- `test/numbers.test.ts`, `test/date-order.test.ts`, `test/sheet.test.ts` and `test/load-errors.test.ts` cover the money shapes, the mixed-style row, the non-finite cells, the separator shapes, the date shapes, the language order and the workbook sheet count.
