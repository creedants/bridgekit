A real sales export was read wrongly in four ways. A European money column of `1.979.849,56` stayed text, so Sales could not be chosen. `NaN` and the infinities filled the bridge. Slash dates with a time failed with the database's own error, and text dates stayed text. A file whose rows mixed `;` and `,` loaded with the wrong delimiter. A file that already worked loads with the same numbers.

- `src/app/numbers.ts` reads a value as a number only when it is finite, so `NaN`, `Infinity` and `-Infinity` stay text and the file problems message names the value and its row. The conversion gate counts a value under either money convention, so a column of many dot groups and a decimal comma reaches the decimal-comma decision. A column that proves two money styles carries the first value of the losing style and its row, when the file proves one, and the Data check sentence quotes both. `mixedSeparatorSentence` refuses a file only when a logical record differs from the header's field count under the sniffed separator while the other separator gives that record the header count with every part filled, decided from the first 64 KB with quotes, skipped rows and comments honoured, so decimal commas and punctuation in text never refuse a file on their own.
- `src/app/db.ts` reads a CSV typed first and retries once when the database reports a conversion error, keeping every date, timestamp and time column as text so the reader can decide from every value. `convertDateColumns` reads slash dates and English month-name dates, with or without a time of day, becomes TIMESTAMP when every non-blank value shares one time format and DATE when none carries a time, and leaves a column text when it proves both slash orders with a real date under each order's full format or mixes shapes. A both-orders note needs one value that parses as a real date under each order; otherwise the column converts under the proved order or stays text. A missing-date note needs a value that matches the shape but names an impossible calendar date, so a bad time or a spelling the shape does not accept stays silent. A month name without a space after the comma reads as a date. The order comes from the values that break the tie, then from the browser's language. The existing slash-date pass takes the same order. Non-finite cells return to the file's own text. `load()` refuses a mixed-separator CSV before it is staged, so the loaded data is left alone.
- `src/app/sheet.ts` returns the name of the worksheet it loaded and how many later sheets have a last used row at row 2 or below.
- `src/app/db.ts` writes that name on a staged workbook, and `src/app/numbers.ts` renders it in the Data check sentence: `The workbook's first sheet, "Sales", was loaded; the other sheet was not.`
- `test/numbers.test.ts`, `test/date-order.test.ts`, `test/sheet.test.ts` and `test/load-errors.test.ts` cover the money shapes, the mixed-style row, the non-finite cells, the separator shapes, the date shapes, the language order and the workbook sheet count.
