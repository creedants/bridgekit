Try again tomorrow.`, which the commentary panel already shows, so nothing in the browser changed. The count is one shared row per member per day, so it holds across Cloudflare's isolates where the per-minute binding does not.
- A request the per-minute limit or the daily cap refuses, and any request from a member without Pro, is refused before the model is called and adds nothing to the day's count. The new `commentary_daily` table arrives with its own migration, which changes no existing row.
