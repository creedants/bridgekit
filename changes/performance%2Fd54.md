- The Data check tab opens with a money tie-out. For the prior and current periods it shows three whole-dollar lines: Sales in file, Excluded by filters, and Sales in the bridge, with Margin wording when a cost column is chosen. Each row's sales and cost are rounded to billionths of a dollar, summed as integers, and rounded to whole dollars, half away from zero. Excluded is the difference of the rounded file and filtered totals. The bridge line follows the Results figure, and the file line is derived by adding Excluded to it, so the displayed file line can differ from the independently rounded file sum. Bridge numbers, effects and existing row counts are unchanged. The Excel Setup sheet carries the same lines, displaying zero where the tab can show negative zero.
