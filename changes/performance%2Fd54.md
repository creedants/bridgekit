- The Data check tab opens with a money tie-out. For the prior and the current period it shows three lines in whole dollars, Sales in file, Excluded by filters, and Sales in the bridge, with the Margin wording when a cost column is chosen, so a finance user can reconcile the bridge to the sales report they already have and see where the excluded rows went. In file minus excluded gives the bridge figure. The file's money and the money the filters keep are summed in whole billionths of a dollar and rounded once, half away from zero, so neither depends on the number of rows. When the money the filters keep for a period ends in exactly half a dollar, the file line can sit one dollar from the exact file total rounded to whole dollars, because it follows the bridge's own figure. Bridge numbers, effects and the existing row counts are unchanged, and the Excel Setup sheet carries the same three lines under the same heading.
