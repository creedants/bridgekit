- The Data check tab opens with a money tie-out. For the prior and the current period it shows three lines in whole dollars, Sales in file, Excluded by filters, and Sales in the bridge, with the Margin wording when a cost column is chosen, so a finance user can reconcile the bridge to the sales report they already have and see where the excluded rows went. In file minus excluded gives the bridge figure. The file and filtered totals are measured in exact integer billionths of a dollar and rounded once, half away from zero, so they do not drift with the size of the file or with how the bridge groups its rows. Bridge numbers, effects and the existing row counts are unchanged, and the Excel Setup sheet carries the same three lines under the same heading.
