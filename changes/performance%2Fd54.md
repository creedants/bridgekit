- The Data check tab opens with a money tie-out. For the prior and the current period it shows three lines to the cent, Sales in file, Excluded by filters, and Sales in the bridge, so a finance user can reconcile the bridge to the sales report they already have and see where the excluded rows went. In file minus excluded gives the same total the bridge shows. Fractional-cent rows round the same way however the bridge groups them. Bridge numbers, effects and the existing row counts are unchanged, and the Excel Setup sheet carries the same three lines under the same heading.
