- `npm run build:cloudflare` reads `VITE_PAGE_COUNTS`, `VITE_WORKSPACES`, and `VITE_AI_COMMENTARY` from the environment. An unset flag stays `1`, so a caller that sets nothing still builds page counts, workspaces, and AI commentary. `npm run build:cloudflare:free` builds page counts only: workspaces off, AI commentary off.
- The Workspace panel renders "Email me a link" only when the deployment can send email. Microsoft and Google buttons still render when those providers are configured. When there is no email delivery and no provider, the panel shows "Accounts are not open yet." and no form. While the config is loading, or the config request failed, the panel shows the Workspace legend and any error, and no form.
- A signed Paddle webhook body that is not JSON returns 400 and "The request was not valid JSON." A missing or wrong signature still returns 401 and "Bad signature."
- `perf/README.md` says the tool-page set can include the DuckDB chunk when the idle callback runs before the harness reads the interactive mark, which happened in 2 of 20 branch loads.
