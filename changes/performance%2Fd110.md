- The Setup panel now offers to leave out a row whose period or attribute value is `Total`, `Totals`, `Grand Total`, `Subtotal`, `Sub-total` or `Sub total`, in any case and with an optional trailing colon, because a spreadsheet export's total row would count the same amounts twice. One query checks the period column and the attribute columns; a matching value shows how many rows carry it and one button that adds an exclude filter for that value, or merges it into the column's existing exclude filter. A column with an include filter, or with the value already excluded, gets no offer, and an offer disappears once the filter covers the value.
- Profiling a loaded file now goes through one function that checks the load count, so a file whose distinct counts and roll-up chains finish after a later file has loaded no longer overwrites the later file's columns or chains. The same count stops an earlier load's row count, preview and source from landing after a newer load.
- T100 was investigated with no code change. The 200-value period cap still exists, as `LIMIT 200` on the ranked list in `src/app/periods.ts`, and it still keeps the 200 largest values and drops the smallest, which a query over 250 numeric periods reproduces.
- Only `src/app/profile.ts`, `src/app/App.tsx`, `src/app/SetupPanel.tsx` and `test/total-rows.test.ts` changed in code.
