- A file picked while an earlier load is still loading now wins. Before, the earlier sample's million rows could land after the file, so the top bar showed the file's name over the sample's totals; the page now writes loads in the order they were picked, and a load a newer pick replaced is skipped only when its write has not started yet, while a write already running finishes before the newer load lands.
- A refused file now leaves the page naming the data that is actually loaded, instead of a name from a load that never reached the table.
- Pasting cells now asks "Replace the loaded data with the pasted cells?" only when data has been drawn on the page, from a loaded file, the sample or a bridge. Dismissing the question changes nothing. A paste before anything is drawn loads the pasted cells with no question, as a newer pick does, including while the engine downloads, while a file reads and calculates, and while the sample's bridge is being calculated.
- The engine used to start downloading at first paint, whatever the visitor's connection asked for. It now starts when the page is idle, and not at all when the browser reports a data-saver preference, through the idle scheduler the page already uses for the results view.
