A CSV with blank lines before its header, a date column that fails for two reasons, and a quoted header holding commas now load as the workbook and the existing notes already did.

- `src/app/db.ts` skips leading blank lines before the header, where a blank line is empty or holds only whitespace or separators, and loads with the header and rows that follow. The skip is the count from the file prefix, passed as the reader skip, so a header-only or empty file after blanks is still refused with no data rows and blank lines inside the data keep their existing handling. The header width check counts fields with quoting respected after those lines, so a correctly quoted header is not refused as too wide. `src/app/numbers.ts` takes the same skip for its dot planning read.
- `src/app/db.ts` names the first impossible calendar date by row order when a date column fails for more than one reason, so a column whose first failure is a bad time but which later holds an impossible date still gets the missing-date note with that value. Columns that already got a note keep the same value.
- `test/numbers.test.ts` and `test/date-order.test.ts` cover the blank-lines load and its physical row, the header-only refusal, the bad-time-first date note, and the quoted header field count and load.
