- A remembered or loaded setup is now checked against the loaded table's column types, not only its column names. A setup whose sales, units, gross or cost column holds text, or whose year, year to date, quarter or month grain meets a column that is not a date, is dropped when it is remembered and refused with one sentence when it is loaded from a file or a workspace. A setup file that is not JSON says so in one sentence instead of showing the JSON parser's message. Export Excel is off whenever the setup-changed notice is shown, and the workbook's Setup sheet describes the run that produced the numbers.
