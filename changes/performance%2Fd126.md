- The written summary now adds up like the bridge table. Every line the named drivers leave out joins the leftover sum, including a line below the old size threshold, so the named lines and the leftover add up to the change. When one line is left, the summary names it: "Mix: Size adds -284." Otherwise it reads "The other 3 lines add up to -222.". Every amount in the summary prints whole with an ASCII sign, as the table does, and the headline prints the two totals whole, from 1,000,000 in 2025 to 1,100,000 in 2026, with more decimal digits only when two totals round to the same whole figure.
- A file that mixes separators now gets a Data check sentence when a period value is a whole record: 18 rows have a period such as "2025;North;A-100;S;10;897" that looks like a whole row. The file may mix separators. Save it again with one separator. One such row reads "1 row has a period such as ...". A valid file with a sparse footer row, a quoted value holding a comma, or a note such as see;notes;here;please says nothing.
- A measure column that is mostly numbers names its first text cell: Sales must be a column of numbers, and "NET_SALES" holds text, such as "n/a" in row 5. The row is the file's own spreadsheet row when the file can prove it. When it cannot, the sentence names no row. The same sentence names the units column. A column that is mostly text keeps the older sentence with no cell.
- A converted number column says how its values were read. A currency sign or brackets reads "Numbers in amount such as €600 were read with the currency sign or brackets removed, as 600." and a comma between thousands reads "Numbers in amount such as 1,000.50 were read with the comma between thousands, as 1000.5.". The parser reads €600, $600 and (520) as 600, 600 and -520, and a quoted 1,000.50 in a comma file as 1000.5. A column that carried neither mark says nothing.
- Suggest attributes leaves out German customer columns named Kunde, Kunden, Kundennummer or Kundennr, beside the English customer words. Produkt, Größe and Farbe are still suggested.
- A month written without a day, as MM.YYYY, MM/YYYY or YYYY-MM, now loads as the first day of that month. The setup picks it as the period with the year grain, the period list holds 2025 and 2026, and the bridge compares the file's yearly totals. A text column of those labels that cannot be converted also sorts by date, not by text.
- An Excel header cell's surrounding whitespace is no longer part of the column name, so a Sales header saved with a trailing carriage return still reads Sales and the Sales box keeps its column.
- A number too large for the short units never prints exponent notation. An amount at or above 10^18 prints 1,000,000T+, and a percentage strictly above 1,000,000% prints >1,000,000% (or <-1,000,000% for a negative). Prices and whole figures print their full grouped digits.
- A file refused because of its width says "This file has too many columns to open in this browser. Save it with fewer columns." A CSV with more than 10,000 header fields is refused before the reader runs, and so is an Excel first sheet with more than 10,000 columns. A large file that runs out of memory keeps "This file is too big to open in this browser. Try a smaller file, or save it with fewer rows or columns.".
