- The sitemap generator now refuses a `vite.config.ts` input block whose opening line carries anything but whitespace after `input: {`, and refuses a closing line other than `}` or `},`. Each refusal exits 1, names the line, and leaves `public/sitemap.xml` unchanged. The sitemap tests assert each root page's own canonical and `og:url` address, and run the generator on a temporary config to pin both refusals.
