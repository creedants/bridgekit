- Adds the engine function `bridgeBy`, which runs the ordinary bridge over the whole loaded file and then one bridge per panel: at most `limit` single-value bridges for the values of the chosen column, such as region, segment, product family or sales rep, largest change first, plus one bridge over all the remaining values together. Each panel runs on that panel's rows alone, with the same periods, measure and settings as the main bridge, and what the panels leave of the main bridge's effects is stated per effect as the mix between them. The column's text form defines a value, so a null and an empty string are one value. A value with no positive prior units is reported with its prior and current sales and no bridge; a value with prior units and no current units still gets a bridge. The call never writes, replaces or drops the main cells table after the main bridge writes it; it drops each claimed helper, retrying a failed drop once, and a helper whose drop fails twice stays until the session ends.
