- Adds the engine function `bridgeBy`, which runs the ordinary bridge once for every value of one column of the loaded file, such as region, segment, product family or sales rep, and once more for all the values left out. Each value's bridge covers that value's rows alone, with the same periods, measure and settings as the main bridge, and what the values leave of the main bridge's effects is stated per effect as the mix between them. The column's text form defines a value, so a null and an empty string are one value. Panels are ordered by the size of their change and a value with no prior units, or with no units in a period at all, is reported without a bridge. The call leaves the main cells table exactly as a plain bridge leaves it and drops the temporary objects it made.
