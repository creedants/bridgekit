- The results page is split by tab. Each view now lives in its own file under `src/app/results/`: the Summary with its optional AI commentary, Accounts, Trend, Setup check, Price changes with its realization table, Price gaps, Movers, Unmatched and the Data check. The small pieces more than one view uses, `display`, `TextCell`, `matchLabel`, `Kpi`, `TableActions` and `CopyButton`, live in `src/app/results/shared.tsx`. `src/app/Results.tsx` keeps the `Results` component, the tab switch, the bridge tab's own markup and the types it exports, and it is 1,133 lines shorter.
- Nothing a visitor sees changed: the same tabs, wording, markup, class names, amounts and percentages, the same downloaded report and the same exported CSV files. The move adds no request, stores nothing and adds no dependency.
- The tab components and the shared cell and KPI helpers are exported from their own files now that they are separate modules, and the five test files that imported them by module path load them from the file that holds them. `test/margin-labels.test.ts` reads the source text of `src/app/Results.tsx` and the ten new files as one set, because the labels it checks for now live across them.
