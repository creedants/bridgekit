- A bridge's rounded effect lines now add up. `roundBridge` in `src/summary.ts` rounds the prior and current totals once and hands the leftover whole units to the effect lines with the largest remainders, so the shown lines plus the shown prior total equal the shown current total and no line moves more than one unit from its exact value. The bridge table and the amounts in the KPIs and the written summary in `src/app/Results.tsx`, the downloaded report's bridge table and summary in `src/app/report.ts`, and the totals sent for AI commentary from `src/summary.ts` all use it. The "% of prior" column, every percentage and share in the written summaries, the Waterfall chart, the Excel export and the CSV exports keep the exact figures.
- On the sample data at `/app/?sample=budget`, the table showed 50,756 plus lines of 611, 475, 414, 444 and -557 against a current total of 52,142, so the lines did not add up; it now shows the same totals with the new configurations line at 443, and the lines add up. On the default sample at `/app/?sample`, the Change figure was 12,541,279 against lines that add up to 12,541,278; it now shows 12,541,278.
- The amounts in the written summary on screen and in the report come from those same rounded figures, while its percentages are computed from the exact bridge. The Like-for-like price KPI, its table line and the summary now print one amount, so a rounded price line of +1 no longer sits beside a KPI of +0.
- The AI commentary prompt now says the totals and effect values are rounded to whole numbers, so one line can differ from its exact value by up to one while the lines still add up, instead of saying the effects add up exactly.
- The Anthropic client in `server/commentary.ts` is built with `maxRetries: 0`, so one accepted commentary request makes one upstream attempt instead of up to three the daily count did not see. The server-side fallback model stays part of that one request.
- The Data check whole-row warning lookup runs once per calculated result and is reused when the page re-renders, so a large clean file is no longer rescanned on every parent render.
- The free Cloudflare build (`npm run build:cloudflare:free`) leaves the AI commentary panel out at build time, so its heading and hint sentences, its button label and its request to `/api/commentary` are absent from the built scripts. A build with `VITE_AI_COMMENTARY=1` keeps the panel and shows it under the same run-time rules as before.
- Only `src/app/Results.tsx`, `src/app/report.ts`, `src/commentary.ts`, `src/summary.ts` and `server/commentary.ts` changed in code.
