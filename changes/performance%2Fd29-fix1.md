- The one limit a single Worker request cannot hold, two invitations written for the last seat at the same moment, is refused by a `BEFORE INSERT` trigger on `invitation` in `migrations/0004_workspace_limits.sql` that calls `RAISE(ABORT)`. The Worker answers that database error with the same 403 "This workspace has no free seat, so cancel a pending invitation or add seats." that an ordinary refusal carries. Every other refusal is asked before a row is written, in the Worker and in the plugin's before-hooks, so no trigger reads, changes or deletes a row of another table, and applying the migration leaves every existing row untouched.
