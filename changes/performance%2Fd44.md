- The smoke run counts enforcing content-security policies on the live `/app/` response and expects that many reports of each blocked control attempt. Each comma-separated policy in a Content-Security-Policy header counts, and each Content-Security-Policy meta element in the document head counts. A report-only header or meta tag does not count. A meta tag in a script, a style, or outside the head does not count. `smoke:preview` requires no policy header and one enforcing meta tag. `smoke:wrangler` requires one enforcing header and one enforcing meta tag. A missing or extra declaration fails and names it. URL mode prints the counts it found. It cannot tell which declarations the server was meant to send. A Bridge check cell passes when its number or its formula result is within 1e-6 of zero. When that formula has a cached numeric result, that result is within 1e-6 of zero too. A blank, missing, or text cell fails and names the cell.
