- The smoke run counts enforcing content-security policies on the live `/app/` response. Each Content-Security-Policy header line counts, and each Content-Security-Policy meta tag counts. A report-only header or meta tag does not count. The run expects that many reports of each blocked control attempt. A Bridge check cell passes only as a finite number that is zero, or as a formula that evaluates to zero. When that formula has a cached numeric result, that result is zero too. A blank, missing, or text cell fails and names the cell.
