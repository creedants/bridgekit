- `bridgeBy` now runs each panel's bridge against a view of that panel's rows and into a cells table whose names are made fresh for the call, so the main cells table is never copied, replaced or dropped, no helper name can collide with a user's table or view or with the source, and two overlapping calls cannot corrupt each other's cells. Every temporary object the call makes is dropped in a `finally`, each in its own `try`, so one failed drop does not skip the others and a cleanup error never replaces the error the body threw. The change note and the `between` comment now say the mix sums to zero only when every panel has a bridge, and otherwise sums to the change of the panels with none.
