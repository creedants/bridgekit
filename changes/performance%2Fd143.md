- Each measure picker offers every numeric column other than the period column, and picking the column the other measure holds swaps the two. Count names take priority over size names for Units, a currency-unit name such as `Sales (Currency Units)` is read as money rather than as a count, and a name that says price, cost, rate or size is never Sales from its values; choosing one shows one non-blocking sentence. Sales name matching includes French, German, Spanish and Dutch money words, and when no name says sales the largest qualifying numeric sum supplies Sales with a note that names it. `src/app/setup.ts` holds the name words, the swap and the hints, and `src/app/SetupPanel.tsx` shows them.
- Dates covering at least two months inside one fiscal year refine an untouched fresh guess from Year or Year to date to Month; the fiscal start is respected, and a restored or edited setup is never refined. The one-period gate points to Compare by only when the file is known to have at least two months, and otherwise keeps the plain two-period sentence. Coverage notes read the same filtered rows as the bridge and ask the visitor to check comparability instead of naming a cause. `src/app/setup.ts` holds the grain rule, `src/app/periods.ts` the coverage statement, and `src/app/profile.ts` adds each column's sum, first date, last date and month count to the profile.
- Attribute suggestions keep one column of an exact or near duplicate pair, whichever side survives the name rules, so a code-first pair still suggests its name. The roll-up hint names its broadest and finest columns, and warns when an identified size column is omitted. A setup note counts the rows with no units but some sales and, among them, the rows whose name reads like a fee or an adjustment; rows are retained. `src/app/profile.ts` finds the pairs and the fee rows.
- An attribute name that is emptied falls back to its column's own name everywhere it is shown or exported, so no bridge line or Excel row is labelled only "Mix:". An attribute row with no column is never added, so Calculate can no longer send an empty column name to the engine and show a raw SQL parser error over an old bridge. `src/app/setup.ts` fills and cleans attribute names, and `src/app/SetupPanel.tsx` applies them.
