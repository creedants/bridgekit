- A loaded file's measures are guessed so that Units and Sales are never the same column, a count column named as a count is chosen over a bottle size or other volume-per-item column, and a column named like a price is not used as Sales. Money column names are now also read in French, German, Spanish and Dutch, and when no name says sales the widest money column is chosen from its values. When the guess is uncertain, one plain sentence beside the Sales picker names the choice made and the column to try instead: a second money column, a column chosen from its values, or Sales that totals less than Units as a per-unit price would. None of these hints blocks Calculate. `src/app/setup.ts` holds the name words and the hint, `src/app/SetupPanel.tsx` shows it, and the pickers no longer offer the column already chosen for the other measure.
- A date file whose dates fall inside one year now starts on Month instead of Year, so Calculate is live on first load; the sentence that says a column gives only one period now names Compare by and Month. When the two chosen periods cover different amounts of time, the setup shows one plain note before Calculate that names both periods and the time each covers, and leaves the choice alone. `src/app/setup.ts` reads the dates the profile reports, `src/app/periods.ts` builds the coverage statement and the sentence, and `src/app/profile.ts` adds each column's sum, first date, last date and month count to the profile.
- A class name and its code, which map to each other one for one, are suggested as one attribute rather than two, and the profile marks the later column of such a pair. The roll-up suggestion now says in plain words which column nests inside which, and when it leaves out a column named like a size or volume it says so in one sentence. Fee-like rows, which have no units and some sales or a name like fee or adjustment, are named in one note on the setup; no row is dropped. `src/app/profile.ts` finds the one-to-one pairs and the fee rows.
- An attribute name that is emptied falls back to its column's own name everywhere it is shown or exported, so no bridge line or Excel row is labelled only "Mix:". An attribute row with no column is never added, so Calculate can no longer send an empty column name to the engine and show a raw SQL parser error over an old bridge. `src/app/setup.ts` fills and cleans attribute names, and `src/app/SetupPanel.tsx` applies them.
