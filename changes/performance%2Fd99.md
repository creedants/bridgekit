- Loading a file that writes money with a currency sign or a currency code now offers that column as Sales or Units where it used to stay text. `€1.234,50`, `1.234,50€`, `EUR1.234,50`, `1 234,50 EUR` and `CHF 1'234.50` load as numbers, and so do thousands grouped with a no-break space, a narrow no-break space, an apostrophe or a right single quote. A trailing minus such as `1,234.50-` reads as negative, and so does a currency value in parentheses such as `(€1.234,50)`. `src/app/numbers.ts` reads the currency marker, the grouping and the sign.
- A column that mixes two currencies stays text and is now named with the existing mixed-styles sentence. A currency sign separated from the digits by a space, such as `€ 12,50`, keeps its current reading as text.
