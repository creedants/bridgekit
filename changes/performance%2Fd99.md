- Loading a file that writes money with a currency sign or code now offers that column as Sales or Units. `€1.234,50`, `1.234,50€`, `EUR1.234,50`, `1 234,50 EUR`, `CHF 1'234.50`, `€12,50`, and `$1,234.50` all read as numbers, and so do thousands grouped with a no-break space, a narrow no-break space, an apostrophe, or a right single quote. A trailing minus such as `1,234.50-` reads as negative, and so does a currency value in parentheses such as `(€1.234,50)`. `src/app/numbers.ts` parses each value once into its currency marker and plain text, and the counts, the formatted check and both column rewrites read that one parse.
- A column that mixes two currencies stays text and keeps the existing mixed-styles sentence, and a value whose currency is separated from the digits by a space, such as `€ 12,50`, keeps its current reading as text.
