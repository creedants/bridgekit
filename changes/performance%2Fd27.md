- A CSV that is not UTF-8 loads. A file from Excel's plain "CSV" export (Windows-1252) is decoded as Windows-1252, and a UTF-16 file is decoded by its byte-order mark, in the browser before the database reads it. A file that is already UTF-8 is handed over unchanged. A file whose text encoding cannot be read shows one sentence: `This file's text encoding could not be read. Save it as CSV UTF-8.`
